# ca-eats

California's version of the restaurant products, built from one pipeline (see `../STATE_EATS_PLAYBOOK.md`):

1. **The web leaderboard** of California's restaurants, a private claude.ai Artifact from `site/index.html`
   (https://claude.ai/artifact/Nj2pmtTTJjsYL2nSovjx9C). Nine regions load on demand. Its JSON is git-ignored because it carries Google
   2021-derived ratings.
2. **California Eats**, a free iPhone and iPad app (App Store name "California Eats: Restaurants", subtitle "Taquería & Dim Sum Guide",
   Home Screen "CA Eats"), with no Google-derived data.
3. **Its website** in `docs/`, generated by `scripts/make-site.py`: landing page, seven guides, MICHELIN & James Beard, oldest places,
   24 city pages, the web app at `/explore/`, privacy, terms. Planned home https://california.eatsranked.com/.

Built separately from `chi-eats/`, `wi-eats/` and `wa-eats/`, reusing their structure, rules and much of their code (read-only). California
adds region files (the state is about five times Wisconsin), four counties' own inspection scales shown side by side but never blended,
statewide ABC license data, MICHELIN Guide California, and accent-folding for names like "Taquería" and "Taco María".

## Calibration (2026-10-07)

Every Overture listing in LA County (minus Pasadena, Long Beach and Vernon, which inspect on their own) and San Diego County was checked
against the county's permitted food facilities (same name nearby, or the same street address with a distinctive name word). Share that
matched, LA County / San Diego County:

| Listing | Matched | Here |
|---|---|---|
| Meta + open in Google 2021 | 87% / 74% | artifact: kept, "two sources" |
| Meta only | 46% / 45% | artifact: kept, "listing only" |
| Foursquare / BrightQuery / Microsoft only | 14–31% / 11–25% | dropped |
| Google 2021 says closed | 4% / 4% | dropped |
| App: Meta, confidence ≥ 0.95 | 86% / 73% | kept, "confirmed listing" |
| App: Meta, 0.90–0.95 | 48% / 44% | kept, "listing only" |
| App: chain store feeds | 74% / 59% | kept |
| App: lower-confidence Meta / BrightQuery ≥ 0.95 | 21% / 28% (LA) | dropped |

Coverage: the app's kept listings hold 61% of LA County's and 58% of San Diego County's permitted restaurants, and 52% of the state's
ABC-licensed restaurants and bars (a lower bound). LA County, San Francisco and Sacramento County restaurants the map data lacks are added
from the county records.
